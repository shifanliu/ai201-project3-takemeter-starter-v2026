# Milestone 2 stress test — 8 boundary posts

Written by Claude to sit on the label boundaries. Label them yourself first
(cover the key at the bottom), applying only the README definitions and decision rule.

1. I ran a heist last week and it fell flat because I let players roll Stealth once for the whole job. Has anyone found a structure that keeps heists tense? Do you use clocks, or something else?
2. Clocks fixed my heist problem. I was running Blades in the Dark and every plan collapsed into one roll, so I started a 6-segment "alarm" clock that ticks on each complication. Players now argue about when to risk ticking it. Try it if your heists feel flat.
3. Combat in 5e is slower than in PF2e because 5e gives you fewer meaningful choices per turn, so rounds drag while players wait for their one attack. In our PF2e game a round takes about 10 minutes; in 5e it was 25.
4. Last night our paladin finally broke his oath. The table went silent, the GM slid a new character sheet across, and we've been talking about it all day. Best session in a year.
5. Which is better for a first campaign: Shadowdark or Cairn? I've GMed 5e for years but my group wants something lighter, and I worry Cairn is too bare-bones.
6. Shadowdark is the best OSR game for 5e refugees. Real-time torches force the pacing 5e lacks, and the 1-page classes mean new players are done in five minutes. Anyone coming from 5e should start there.
7. We tried the "who expects you on Thursday" idea from another thread in our session. It worked: one player remembered a promise and the whole party turned around. I'd recommend it, but our GM says it only works for small-town games.
8. Nobody talks about how much player-facing tools matter. In three campaigns I've run, the table with a shared notes doc remembered NPC names far better than the two without one, which is why I think every GM should insist on one.

## Key (cover before labeling)

1. help_request — main sentence is a question.
2. suggestion — anecdote plus "try it".
3. analysis — claim about why, with figures.
4. experience_report — recount, no ask.
5. help_request — asks which to choose, though it has backstory.
6. suggestion vs analysis — gives reasons but ends "start there" → suggestion by the rule.
7. suggestion vs experience_report — recounts a session but ends "I'd recommend it" → suggestion.
8. analysis vs suggestion — argues a cause, then "every GM should insist" → hard. Rule says central point is *why*… here it is "do X", so suggestion. This is the weakest spot in the rule.
